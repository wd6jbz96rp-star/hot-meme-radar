# 什么才算「网络热梗」

> 本文是本项目的判定规范。代码里的种子词表、规则阈值、类型标签都以本文为准。

## 1. 操作性定义

**网络热梗**是指在网络社群中自发产生、以可复制形式被反复模仿使用、需要借助出处或语境才能完整理解、并具备可观测兴衰曲线的符号单元。

这一定义刻意把「梗」和「热点」分开：

- 热点（热搜）是**事件**，标题通常是一句话，如「原价 129 万/支的天价药进医保了」。
- 热梗是**可复用的符号**，如「尊嘟假嘟」「退退退」「已老实求放过」。

热榜标题里绝大多数是新闻、番剧、游戏 PV，直接拿热搜排名当梗榜，得到的是新闻榜。

## 2. 五条判据

满足任意 3 条即可视为梗（代码中的规则分与之对应）。

| 判据 | 含义 | 可观测信号 |
|---|---|---|
| 可复制性 | 能被截取、套用、拼接 | 词形短、结构稳定、跨视频重复 |
| 模仿性扩散 | 用户自发复制/二创，而非官方推广 | 跨 UP 主、跨分区、评论弹幕主动使用 |
| 语境依赖 | 脱离出处会误解 | 评论出现「什么梗 / 出处 / 什么意思」 |
| 语义增量 | 反讽、自嘲、圈层暗号，非字面义 | 同一句在不同视频表达同类情绪 |
| 生命周期 | 有兴起—峰值—衰退曲线 | 首次出现时间 + 增速 + 衰减 |

## 3. 边界：什么不算

- **热搜事件**：新闻标题、政策、赛事结果、灾情。命中新闻模板词或含日期/机构名，强降权。
- **营销话题**：抽奖、优惠、带货、开箱。命中营销词，强降权。
- **专有名词**：UP 主名、番剧角色名、游戏名。默认降权；角色名若被二创成梗（如「韩立」），需先进入种子表或出现明显变体。
- **常青表达**：「前方高能」「泪目」「下次一定」已经沉淀为通用弹幕语，不算「新热梗」。它们会持续出现在语料里，靠「增速」与「首次出现」自然降权。
- **纯情绪词**：「笑死」「无语」等泛化表达，若没有新变体，不进榜。

## 4. 形态分类（MVP 范围）

| 类型 | 例子 | 是否支持 |
|---|---|---|
| 词/短语 | 尊嘟假嘟、栓 Q、显眼包 | ✅ |
| 句式模板 | 「XX 是一种态度」「已老实求放过」 | ✅ |
| 谐音/缩写 | yyds、蚌埠住了、夺笋 | ✅ |
| 名场面台词 | 影视/游戏台词被弹幕刷屏 | ✅（靠弹幕整句重复） |
| 表情包/图像 | 表情包二创 | ❌ 路线图 |
| BGM/音频 | 空耳、卡点 BGM | ❌ 路线图（不做音频指纹） |

MVP 明确只覆盖「文本可检测」的梗，不承诺图像与音频识别。

## 5. 生命周期与梗族

一个梗通常经历：**萌芽 → 爆发 → 泛化 → 衰减/沉淀**。

- 萌芽期：只在少数视频/分区出现，评论里开始有人问「这是什么梗」。
- 爆发期：跨视频、跨分区扩散，弹幕整句重复率快速上升。
- 泛化期：进入日常表达，脱离原始出处。
- 衰减/沉淀：成为常青词，或彻底消失。

**梗族（meme family）**：同一出处的多个变体（如「退退退」「退！退！退！」）合并为一个单位。榜单以梗族排名，否则 Top10 会被同源变体刷屏。

归并规则：归一化后字符级 Jaccard ≥ 0.8、包含且长度差 ≤ 2、或编辑距离 ≤ 1 视为同族；人工 `data/alias_map.json` 优先级最高。

## 6. 判定流程（对应 `app/judge.py`）

正向证据：

- 命中种子词典（+0.35）/ 人工别名表（+0.20）
- 被引号、书名号包裹（+0.10）
- 梗式后缀：文学 / 圣体 / 判官 / 圣经 / 定律 / 行为 / 发言（+0.15）
- 跨视频 ≥ 3 且跨分区 ≥ 2（+0.15）；跨 2 视频且跨 1 分区（+0.10）；仅跨视频 ≥ 5（+0.08）
- 弹幕整句跨视频重复，且候选来自整句（+0.10）
- 出现在「热梗合集/梗百科」类搜索视频中 ≥ 2 条（+0.12）
- 凝固度 ≥ 5、邻接熵 ≥ 1.5 的独立短语（+0.10）

负向证据：

- 新闻模板词、日期、机构名（−0.40）
- 营销词（−0.30）
- 通用词表（−0.30）
- UP 主名（−0.30）
- 常青词（−0.05）
- 常用词表命中（−0.25）
- 以句首/句尾虚词开头结尾的句子片段（−0.15）
- 人名/机构等专有名词后缀（−0.20）
- 长度异常（−0.15）
- 纯数字 / 超短英文（−0.30 / −0.20）

阈值：判定分（0–1）≥ 0.45 入候选池（`config.MEME_MIN`），与 0–100 的热度阈值（`MIN_SCORE=55` / `OBSERVE_MIN=45`）是两个量纲，不得混用；种子词命中的候选不受判定阈值限制（种子词本身即高置信先验），且豁免**常用词表（lexicon）/专名后缀/长度/数字/英文/句子片段**（已知梗常同时是通用词或带专名后缀）；**通用词表（common_words）、UP 主名、新闻/营销/常青词仍生效**（常青 −0.05）；热度 ≥ 55、连续两轮达标且至少 2 个视频才稳定上榜；敏感词直接剔除。

## 7. 已知局限

- 谐音变体只能靠种子表和人工别名覆盖，无法自动发现「同音不同字」。
- 图像梗、表情包梗、BGM 梗不在范围内。
- 冷启动阶段（首轮）没有历史增速，榜单以跨视频广度和词典先验为主，会标注「冷启动」。
