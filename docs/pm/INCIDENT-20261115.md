- 没有新增/修改业务行；当前字节等于 00:11 的只读副本，逻辑内容 == 00:11 快照。

## 4. 处置

1. 不再对生产库做任何写操作；后续所有脚本必须显式 `HOTMEME_DB=/tmp/*.db`。
2. 建议在切榜/重启前，把当前 `data/hotmeme.db` 复制一份到 `/tmp` 作为新基线（只读操作）。
3. agent/测试运行规则：`HOTMEME_DB` 未显式设置时，禁止调用 `store.connect()` / `store.init_db()`；PM 在验收时检查 env。
4. 生产库恢复：**不必要**——当前字节与 00:11 副本完全一致；若未来需要干净基线，用该副本覆盖即可（但会再写一次，需用户批准）。

已止损、已取证、未再写；`WARM-EVAL.md` §8 留有原始记录。需要用户知悉：这不是业务数据损坏，但属于流程事故。
