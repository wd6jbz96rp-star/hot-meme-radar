## 1. 改了什么

### P0-1 量纲错误

- 新增 `config.MEME_MIN = 0.45`，与 0–100 的 `MIN_SCORE/OBSERVE_MIN` 分栏；
- 新增 `judge.passes_meme_gate(meme_score, seed_hit)` 作为唯一入池判定，`pipeline` 改用它；删除死代码 `judge.decide()`；
- 判定分 `round(...,3)`，修 `0.15+0.10+0.10+0.10=0.4499…` 的浮点边界（有回归测试）。

### P0-2 判定规则自洽

- 种子豁免：恢复 `lexicon`、`proper_noun` 豁免（PM #2：已知梗很可能同时是通用词或带专名后缀）；保留 `evergreen` 降权 −0.05；长度/数字/英文/句子片段继续豁免。
- 非种子正向上限由 0.25 提至约 0.70；文档化组合「跨视频/跨分区 0.15 + 弹幕重复 0.10 + 引号或后缀 0.10/0.15 + 独立成词 0.10」≥ 0.45，回归测试覆盖。
- `MIN_VIDEOS_FOR_RANK=2` 接入 `status_for`：`hot` 需 ≥2 个视频。
- `CONFIRM_ROUNDS=2` 接入且修正偏移：`rounds=max(1, CONFIRM_ROUNDS-1)`。
- 移除种子旁路 `NEWCOMER_PERCENTILE`：新晋统一要求曝光分位 ≥0.95。
- `data/blocklist.json` evergreen 补入：吃瓜、麻了、赢麻了、闹麻了、今夕是何年（docs/01 §3 常青/纯情绪词口径，非今日 Top10 专属补丁）。

### P0-3 `is_new`

- `meme_signal.is_new` 落库 + `store.top_items` 返回 bool，`/api/top` 自动透传；
- 语义：**「梗族首次出现在本系统观测历史中即本轮」**（`first_seen_map` 在本轮 `upsert_memes` 前读取）；
- 旧库 `init_db` 检测缺列后 `ALTER`；生产库副本验证 `integrity_check=ok`、可读。

## 5. 根因与遗留风险

1. **真机 Top10 仍全种子**：非种子稳定证据上限约 0.39（跨视频/分区 0.15 + 弹幕 0.10 + 梗源 0.12 + 独立成词 0.10），而其中一条（弹幕/梗源）并非每个族都有；0.45 需要 4 条证据同现，真实非种子多为 3 条。这是证据抽取问题，PM 已确认不靠降阈值解决。
2. **种子仍可长期上榜**：种子豁免入池阈值（docs/01 §6），`meme` 只占综合分 0.12，热度主导；本轮负向豁免恢复后种子分数回到 0.57–0.77，Top10 集合不变。
3. **候选发现仍是更大瓶颈**：黄金集端到端 3/30，低于历史 5/30（候选波动），与 gate 无关。
4. **生产库并发副作用**（非本会话）：`data/hotmeme.db` 出现 cycle#3（14:14:29–14:15:11）与 `is_new` 列；`app/static/index.html` 被并发会话修改。本会话真机只用 `/tmp/wave2a-b.db`。
