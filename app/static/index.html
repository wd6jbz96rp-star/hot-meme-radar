字段口径

  • status模块状态 hot / rising / 其他（观察）
  • publishable发布门标记，不等于已发布
  • 2×2证据覆盖 ≥2 个视频 × ≥2 个维度

数据来源与边界

B站公开榜单 / 搜索 / 评论 / 弹幕语料，由 meme_info 模块生成只读报告。

页面只轮询 /api/meme-info；不请求历史接口、不触发采集、不保存用户身份。

已知限制

报告由外部 worker 周期生成（约 860s），页面本身不刷新数据。

无历史曲线 / 无 SSE；报告缺失、损坏或过期时如实标注，不伪造数据、不回退旧接口。
